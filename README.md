# Walter the Waiterbot
This project was created for Principles of Integrated Engineering F'24.

Across 8 weeks, our interdisciplinary team of 5 engineering students built an autonomous waiter robot. The robot uses computer vision, wheel encoders, and pressure sensors to navigate to specific destinations and deliver trays of food to customers. This repository houses the robot's codebase, which consists of a full sensing and navigation stack built entirely in ROS2.

To read more about the development and technical details of our project, please view the [project website.](https://olincollege.github.io/pie-2024-03/waiterbot/) To learn more about the software housed in this repository, [view the software design page.](https://olincollege.github.io/pie-2024-03/waiterbot/Technical-Details/Software.html)
